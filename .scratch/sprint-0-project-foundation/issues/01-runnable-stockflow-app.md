# 01: Set Up Runnable StockFlow Application

**What to build:** A developer can start StockFlow and see an accessible starting page that identifies the product without implying that authentication or business workflows are available.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] StockFlow runs as a Next.js and TypeScript application using the package manager and commands established by repository configuration.
- [ ] The starting page clearly identifies StockFlow and does not imply that authentication or business workflows are available.
- [ ] The starting page is accessible and responds successfully when loaded.
- [ ] No database, authentication, business modules, deployment infrastructure, or unapproved architectural patterns are introduced.
